# Strix scan of a local copy — 2026-10-21

Run: GitHub Actions "Strix security scan", run 4 on `main` (`aa051f8`), scan mode `standard`, against a throw-away local copy (local Supabase, production build, two seeded businesses). Production was not touched. The model was the one configured in the repository secrets.

**Result of the run:** the run was stopped by the 150-minute limit (exit "missing"), not finished by Strix. Strix had already reported findings. The job log keeps only the last 5000 lines, so VULN-0008 to VULN-0012 were first read from it; **VULN-0002 to VULN-0007 were read later from the uploaded artifact** `strix-evidence-39668442814` (there is no VULN-0001 in it) and are in the section "Findings only in the artifact" below. The model was `openrouter/minimax/minimax-m3.1-flash:free` (a free one, from the attempt log).

| ID | Severity (Strix) | Finding | Status |
|---|---|---|---|
| VULN-0008 | High (7.3) | A customer is identified only by the phone number typed on the public form. Someone who knows a customer's number can use up that customer's booking and waitlist limits at one business and set the e-mail on the customer's record.
